# Alarm Prototypes

Prototipos de la aplicación de alarmas elaborado para la materia **misw4302-2026-11-ux-mejoramiento-de-la-experiencia-de-usuario**. El proyecto incluye dos implementaciones basadas en los diseños de **Figma**: una **web** y una **móvil (Android)**

## Contenido del repositorio

| Carpeta                 | Descripción                                                                  |
| ----------------------- | ---------------------------------------------------------------------------- |
| **[web](./web/)**       | Aplicación web (Angular) con login, dashboard y gestión de usuarios.         |
| **[mobile](./mobile/)** | App Android (Kotlin) con flujo de bienvenida, crear cuenta e iniciar sesión. |

Cada submódulo tiene su propia documentación con estructura, tecnologías e instrucciones de instalación:

- [README web](./web/README.md) — Estructura, tecnologías, instalación y pantallas generadas.
- [README mobile](./mobile/README.md) — Estructura, tecnologías, instalación y pantallas generadas.
